## Бэклог

### 1. Конкуренция вкладок — главная боль
Воркер и автопилот одного акка делят ОДИН Chrome. Воркер циклично
перезагружает ленту и чистит «лишние» вкладки, автопилот параллельно
открывает вкладки заказов. Улики: `FEED_CAPTURE_ERROR: response … navigated
away` (страницу унесли во время чтения), брошенные табы `n.php?o=…`,
кооперативный костыль send-pause (240 с). Варианты решения:

- **(а) Один драйвер на Chrome** — единственный процесс владеет браузером,
  воркер/автопилот шлют ему команды через очередь в SQLite. Правильно, но
  серьёзный рефактор.
- **(б) Короткий межпроцессный лок на каждую навигацию** (не только на
  отправку) — дёшево, смягчает, но не устраняет.
- **(в) Строгий раздел владения вкладками**: воркер владеет только
  feed-вкладкой, автопилот — только своими order-вкладками; таб-гигиене
  запретить трогать чужие. Небольшой рефактор, высокий профит.
- **(г) Слоты времени**: автопилот отправляет в окнах между циклами воркера.

### 2. Сторож Chrome
С `NO_LAUNCH=1` упавший Chrome никто не поднимет. Нужен лёгкий сторож
(powershell-скрипт раз в 5 мин: нет ответа CDP :9222/:9223 → старт нужного
профиля) или ритуал на владелец. Без него режим NO_LAUNCH — только для
дня, когда за машиной сидят.

### 3. Автоперезапуск воркеров на Windows
Обёртка-луп (restart каждые 120 с) есть только у автопилота. Воркер умер —
лежит до ручного вмешательства. Варианты: schtasks при логоне/раз в N мин на
`start-win.ps1` (он идемпотентен? — проверить дубли) или обёртка-луп как у
автопилота.

### 4. thinking-токены glm-5.3-flash
Модель по anthropic-протоколу отдаёт `thinking` + `text`; размышление ест
`max_tokens` (при 16 токенах ответ пустой). Рабочие вызовы используют
3000–4500 — следить за обрезками текстов; при росте «LLM/JSON»-ошибок
вспомнить этот пункт.

### 5. Ротация ключей и лимиты
`root .env` держит старый общий ключ (дефолт для standalone-запусков).
При упоре обоих акков в лимит — добавить третий ключ или снизить темп
(`PROFI_MAX_TRIES_PER_PASS`). Ключи живут только в `accounts/*.env`
(gitignore ✅), в git не попадают.
